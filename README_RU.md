# Pool Aim Overlay — прототип Android-приложения

Это исходный проект на Kotlin для Android 8–15, рассчитанный на сборку в Android Studio или AndroidIDE. APK **не включён**: в текущем окружении нет Android SDK для проверенной сборки.

## Что делает
- Запрашивает разрешение «Поверх других приложений».
- Отображает прозрачный слой поверх игры и плавающие кнопки «Играть / Настроить» и «✕».
- В режиме «Настроить» можно перетаскивать белый маркер битка, жёлтый маркер прицельного шара и голубой маркер направления удара.
- Рисует ориентировочную траекторию, столкновение с одним прицельным шаром и отражения от прямоугольных бортов.
- В режиме «Играть» основной прозрачный слой пропускает касания в игру.

## Ограничения
- Это **ручной** прицел: приложение не считывает картинку игры и не распознаёт шары автоматически.
- Положение бортов задано приблизительно (7,5–92,5% ширины и 20–80% высоты экрана), поэтому для точной калибровки потребуется доработка.
- Физика упрощённая: без спина, трения, силы удара, луз, нескольких шаров и точной игровой геометрии.
- Нет гарантии совместимости с правилами 8 Ball Pool. Использование оверлеев может нарушать правила игры.

## Как собрать на телефоне
1. Установить AndroidIDE из официального источника и настроить Android SDK/Gradle в нём.
2. Распаковать архив, открыть папку `PoolAimOverlay` как Gradle-проект.
3. Выполнить сборку `assembleDebug` и установить полученный `app-debug.apk`.
4. Открыть приложение, разрешить показ поверх других приложений, затем нажать «Запустить прицел».

Если AndroidIDE не поддерживает указанные версии Gradle/Kotlin, потребуется подобрать совместимые версии плагинов. Проект не был собран и проверен на реальном устройстве.


## Облачная сборка без компьютера (GitHub Actions)
1. Создайте пустой публичный или приватный репозиторий GitHub.
2. Загрузите **содержимое** этой папки в корень репозитория, включая скрытую `.github/workflows/build-apk.yml`.
3. Откройте Actions → Build Android APK → Run workflow (либо дождитесь запуска после push).
4. После успешного запуска откройте его страницу и скачайте артефакт `PoolAimOverlay-debug-APK`. Внутри будет `app-debug.apk`.

**Важно:** сборка через GitHub Actions не выполнялась и APK пока не проверен на телефоне. GitHub Actions может потребовать включить Actions в настройках репозитория.
