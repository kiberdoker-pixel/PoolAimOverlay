# AimX AI — этап 33: Android-тест реальной модели на скриншоте

Это **полный Android-проект** на основе ранее предоставленного `PoolAimOverlay_CloudBuild.zip`, а не набор отдельных фрагментов. Добавлена кнопка «Тест нейросети на скриншоте»: выбор изображения через Android, касание центра предполагаемого шара и вычисление оценки настоящей моделью `.ptl` в фоновом потоке. Исходный ручной прицел сохранён.

## Проверка на телефоне
1. Собрать проект через GitHub Actions / Android Gradle (см. `.github/workflows/build-apk.yml`).
2. Установить APK, открыть приложение и нажать «Тест нейросети на скриншоте».
3. Выбрать оригинальный скриншот игры и коснуться центра шара, затем фона для сравнения.

## Ограничения
- Это **не работа в реальном времени** и **не готовый AI-прицел**: модель оценивает только вручную выбранный фрагмент. Автоматический поиск шаров и битка, интеграция MediaProjection и расчёт траекторий по результатам AI отсутствуют.
- Модель обучена на кропах 84×84 исходных скриншотов 3200×1440. Другой масштаб и разрешение могут давать неверный результат.
- Проект **не собран и не испытан на Android** в текущей среде. Зависимость `org.pytorch:pytorch_android_lite:1.13.1` и совместимость с Gradle/SDK требуют проверки облачной сборкой.
- Если сборка падает, смотри логи GitHub Actions; это не готовый APK.
- Выбор изображения не отправляет его на сервер: анализ локальный.
