# AimX AI — этап 35: исправление перед облачной сборкой

Исправлен найденный дефект предыдущего проекта: разрешение `FOREGROUND_SERVICE_SPECIAL_USE` было дважды записано в `AndroidManifest.xml`.

Добавлена проверка `tools/preflight.py`, запускаемая GitHub Actions **до** Gradle: проверяются XML, отсутствие дубликатов разрешений, наличие модели и Kotlin-файлов.
