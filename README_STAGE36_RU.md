# AimX AI — этап 36: первая попытка получить APK

Этот архив — полный исходный Android-проект на основе этапа 35.

## Исправления
- Тест нейросети теперь показывает вероятность ниже 50%, а не скрывает её фильтром.
- Пиксели скриншота читаются один раз при выборе, а не на каждое касание.
- Устаревшие результаты не перезаписывают текст после выбора нового скриншота.
- GitHub Actions сохраняет APK как артефакт на 14 дней.

## Как собрать APK с Android-телефона
1. Открой https://github.com/kiberdoker-pixel/PoolAimOverlay .
2. Важно: ZIP не устанавливается как APK. Файлы архива нужно поместить в корень репозитория, сохранив каталоги `app/`, `.github/workflows/`, `tools/` и файлы Gradle. Через мобильный браузер GitHub массовая загрузка дерева неудобна; можно воспользоваться редактором github.dev или другим Git-клиентом на Android.
3. Открой вкладку **Actions**, выбери **Build Android APK**, нажми **Run workflow** (если доступно). Публикация в `main` также запускает сборку.
4. После успешной сборки открой запуск → **Artifacts** → **PoolAimOverlay-debug-APK** → скачай ZIP с `app-debug.apk`.
5. Если сборка упала, пришли текст первой ошибки из шага **Build debug APK**.

## Ограничения
- В этой среде нет Android SDK/Gradle, поэтому полноценная сборка APK здесь **не запускалась**.
- Это отладочная версия, проверка модели на выбранном скриншоте и ручной оверлей. Автоматического поиска всех шаров пока нет.
- При установке APK Android может предупредить об установке из неизвестного источника.
