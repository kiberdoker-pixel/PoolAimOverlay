# AimX AI — этап 34: подготовка облачной сборки APK

Это **полный исходный Android-проект**, а не APK. Модель пока классифицирует выбранный пальцем фрагмент скриншота; автоматический поиск всех шаров отсутствует.

## Как собрать APK на телефоне через GitHub

1. Открой https://github.com/kiberdoker-pixel/PoolAimOverlay .
2. Перед загрузкой сделай резервную копию текущего проекта.
3. Замени файлы репозитория файлами из этого архива, **сохранив пути**, включая скрытую папку `.github/workflows/`. GitHub через браузер может быть неудобен для массовой загрузки; при необходимости используй загрузку файлов через мобильный браузер в режиме ПК.
4. Открой вкладку **Actions** → **Build Android APK** → **Run workflow**. Если вкладка Actions выключена, включи её в настройках репозитория.
5. После завершения сборки открой запуск и скачай артефакт **PoolAimOverlay-debug-APK**. Внутри будет `app-debug.apk`.
6. Установи APK на телефон и открой **«Тест нейросети на скриншоте»**.
